# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. Two players can play against each other and enjoy the classic X and O game.

## 🌐 Live Demo

[Play Tic Tac Toe](https://sumitkumar044.github.io/Tic-Tac-Toe/)

## 🚀 Features

- Two-player gameplay (X and O).
- Interactive game board.
- Automatic winner detection.
- Draw detection.
- Reset game functionality.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript – Game logic and functionality

   ```bash
   git clone <repository-url>
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing!

## 🎯 How to Play

1. Two players take turns.
2. Player X starts the game.
3. Players select an empty cell to place their symbol.
4. The first player to get three symbols in a row, column, or diagonal wins.
5. If all cells are filled and nobody wins, the game is a draw.
